Ton bot, sur ton ordinateur.

La simulation lit les callouts sans achat, publication ou envoi Telegram.

Pour le mode réel, conserve dans data les fichiers pump_wallet.txt et pump_token.txt. Initialise Telegram une première fois depuis le terminal. La variable JUP_API_KEY doit être définie dans la fenêtre qui lance cette interface.

Le tableau de bord reprend les journaux du hub. Arrête l’ancien hub avant de démarrer ici. Le bouton Arrêter suspend le suivi ; les positions restent dans le wallet et le journal.

Les états « disponible » vérifient la présence locale des accès, pas leur validité auprès du fournisseur.
