# Repères pour les prochaines reprises

Pour toute demande concernant **Wallet Radar**, la surveillance Helius/WebSocket des wallets ou son affichage GMGN, lire d'abord [la fiche interne](docs/WALLET_RADAR_REFERENCE_INTERNE.md), puis les fichiers concernés.

Le nom **Wallet Radar** désigne ce bot précis, distinct du bot de republication de callouts et de l'analyse Discord. La fiche consigne le fonctionnement, les choix validés, les chemins de déploiement, les mesures et le dépannage.

La fiche est un instantané daté : vérifier le code et la liste publique des wallets dans la configuration du déploiement avant une modification. Ne pas recopier de clés API, mots de passe, clés privées ou fichiers de configuration secrets dans cette documentation.

Après un changement significatif de Wallet Radar, actualiser la fiche pour qu'une reprise après compression puisse s'appuyer sur le projet, sans dépendre de la conversation complète.
